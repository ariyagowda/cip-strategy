# CIP Strategy

A strategic planning and execution platform for public agencies, focused on stakeholder tracking, action management, and service planning workflows.

## What it does
CIP Strategy centralizes planning artifacts that are often scattered across documents and spreadsheets by organizing:
- Agencies and projects
- Stakeholders (roles, influence, contact context)
- Action items / tasks (owners, due dates, status, notes)

## Why I built it
Planning and execution break down when ownership and next steps live in too many places. This project focuses on making execution visible and easy to maintain over time, while keeping the structure flexible as requirements evolve.

## Tech
- Next.js + TypeScript
- Supabase (Postgres)
- Relational data modeling + CRUD workflows

## Status
Work in progress — this repo represents an actively evolving product.
